OX MODE — PORTABLE STATIC SITE

VIEW LOCALLY
1. Unzip the folder.
2. Double-click index.html.
3. It should open in your default browser. You can also right-click index.html
   and choose Open with > Google Chrome.

PUBLISH WITH GITHUB PAGES
1. Create a new GitHub repository.
2. Upload everything inside this folder to the repository root.
3. In the repository, open Settings > Pages.
4. Choose "Deploy from a branch", select the main branch and /(root), then save.

CONTENTS
- index.html: the complete one-page site
- styles.css: the complete visual design
- og.png: the Ox Mode illustration and social-sharing image
- .nojekyll: tells GitHub Pages to serve the files without Jekyll processing

This portable copy has no server, database, account system, tracking, or shop.
